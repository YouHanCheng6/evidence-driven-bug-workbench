# Public export boundary — personal showcase edition

This tree combines the public DeerFlow base with sanitized copies of the author's current custom workflow files. It is a source-and-design showcase, not an upstream-only snapshot and not a production-ready distribution.

Included: workflow/state contracts, ticket and attachment fact preparation, source-only views, bounded Tabby retrieval, exact current-checkout validation, one read-only Codex investigation, four-section report validation, deterministic note projection/readback, main-assistant batch adapters, frontend projections, and fictional examples.

Excluded: company repositories and Tabby corpora, tickets, attachments, logs, traces, databases, private business rules, credentials, personal Agent files, internal endpoints, enterprise fixtures, original Git history, upstream Actions, and demo conversations.

New runs stop after the verified ticket note. They do not start OpenHands, auto-repair code, run tests, create commits, or change ticket status. Historical diff/rollback fields may remain readable for compatibility.

See `PERSONAL_EXPORT_MANIFEST.json` for the copied files and hashes. Repository, product, person, package, model, and endpoint values are fictionalized; the original replacement map is intentionally absent. Run the offline checks in `README.md`, then manually inspect the complete staged diff and use an independent secret scanner before publication.
